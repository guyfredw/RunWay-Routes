# RunWay Routes

A free website, in development, that generates running routes with fewer stops. Runners choose a starting point, distance, course type and elevation, then download a GPX file for a COROS or Garmin watch.

## Status
Early prototype. There's no website yet. A command-line test is checking whether the routing approach works before the site is built.

- [Product plan](route-planner-plan.md)
- [Routing prototype and test results](prototype/README.md)

## Map data
Routes use data from [OpenStreetMap](https://www.openstreetmap.org/copyright), © OpenStreetMap contributors, and are generated with [BRouter](https://github.com/abrensch/brouter).

## Safety
Routes and stop counts are estimates from map data. They aren't guaranteed to be safe, accurate or passable, so follow local traffic rules and use your own judgment.
